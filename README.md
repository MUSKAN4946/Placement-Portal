# Placement Portal

A full-stack web application designed to help students manage and improve their placement preparation through resume analysis, job recommendations, mock interviews, and profile management.

## Features

- Secure user registration and login
- JWT-based authentication
- Password hashing for secure credentials
- Resume upload and skill-based resume analysis
- Resume improvement suggestions
- Job recommendations
- Save and manage recommended jobs
- Editable student profile
- Mock interview practice
- Interview scoring and performance evaluation
- Interview history and analytics
